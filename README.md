# Programación Modular

Prácticas de programación modular en Java (DAW): estructura y organización del código en paquetes y clases, con pruebas unitarias JUnit. El proyecto está en `Modular/`.

## Requisitos

- JDK 25 y Maven (o IntelliJ IDEA, que los incluye).

## Cómo ejecutarlo

```bash
mvn compile
mvn test      # si el proyecto incluye pruebas
```
